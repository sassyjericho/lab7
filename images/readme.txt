Folder for animal images.

To use real photos, run:
	python download_real_animal_images.py

The script downloads real animal photos from Wikipedia and saves them as PNG files with these names:
	Vaca.png, Cal.png, Iepure.png, Oaie.png, Capra.png, Caprioara.png, Elefant.png, Girafa.png, Panda.png, Koala.png,
	Leu.png, Lup.png, Tigru.png, Pantera.png, Gepard.png, Hiena.png, Rechin.png, Crocodil.png, Vultur.png, UrsPolar.png,
	Urs.png, Porc.png, Maimuta.png, Arici.png, Rata.png, Cainele.png, Pisica.png, Gasca.png, Veverita.png, Soarece.png
